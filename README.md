# BR4M.tv

Recreation of [br4m.tv](https://br4m.tv/) — dark purple light-strings hero, Climate Crisis wordmark, YouTube CTA.

## Stack

- Vite (vanilla)
- Raw WebGL light-strings background (same shader math / colors as the live site)
- Google Fonts: Climate Crisis + DM Sans

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Static output lands in `dist/` and can be deployed to any static host.
